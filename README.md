# Week 1: Data Acquisition, Cleaning, and Preprocessing

## Overview
This project demonstrates data acquisition, cleaning, and preprocessing using Python on the publicly available Titanic passenger dataset.

## Objectives
- Load and explore a public dataset.
- Identify and handle missing values.
- Check duplicate records and inconsistent data.
- Detect potential outliers using the IQR method.
- Visualize data distributions.
- Export the cleaned dataset for further analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
[Titanic Dataset (CSV)](https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv)

## Project Workflow
1. Data acquisition
2. Exploratory data analysis
3. Missing-value treatment
4. Duplicate and data validation checks
5. Outlier detection
6. Data visualization
7. Export cleaned data to CSV

## How to Run
1. Open the notebook in Google Colab.
2. Run all cells from top to bottom.
3. Review the outputs and visualizations.
4. Download the generated `titanic_cleaned.csv` file.

## Output
A cleaned Titanic dataset ready for further exploratory data analysis and machine learning.
